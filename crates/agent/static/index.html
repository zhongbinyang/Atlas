          使用说明
          
    
            
  • 手工变量按本机台保存在中心；改完后需点保存。
    • 
            
  • 单位由中心 WebUI「单位」页全局维护，本页不可编辑；Spec 下拉自动读取。
    • 
            
  • 设备 / 校准可各保存多套配置档，各自启用一套；展开区可编辑当前档的 ${Section_Key} 值与说明。
    • 
            
  • 展开优先级：通道 overlay > 手工变量 > 当前设备档 > 当前校准档；Hostname / IP 仍随本机刷新。
    • 
            
  • 配置档中的数组在 ${…} 展开时可选择兼容分号或原始 JSON（顶栏「数组展开」，需保存）。
    • 
            
  • 支持导入 .ini / .toml 为配置档；查看可导出 TOML。
    • 
            
  • 入参等处输入 / 打开变量选择器。
    • 
            
  • 通道：每台机可配置多个通道及扁平 overlay；序列运行时对各已启用通道并行执行，共用仪表用步骤资源名互斥。
