# 调度中心与 Agent 前端 UI 重设计规格

**日期：** 2026-07-15  
**状态：** 已批准（待实现计划）  
**依赖：**

- `docs/superpowers/specs/2026-07-15-scheduler-agent-design.md`
- `docs/superpowers/specs/2026-07-15-agent-screenshot-design.md`
- `docs/superpowers/specs/2026-07-15-agent-file-browser-design.md`

**范围：** 仅 WebUI 信息架构、视觉令牌、静态资源组织与前端交互呈现；**不改变** REST API、轮询、调度语义、截图归档、文件代理规则。

## 1. 目标

在保持全部现有功能的前提下，将调度中心（`:26630`）与 Agent（`:26631`）内嵌 WebUI 升级为统一的「产线工控清爽」观感，并以 **Agent（机台）优先** 重组调度中心信息架构。

成功标准：

- 调度中心默认落在「机台」视图；顶栏品牌「调度中心」为一眼可见的主信号。
- 「作业」视图覆盖现有模板与任务全部能力；截图、历史、文件仍由机台行打开模态完成。
- Agent 首屏为状态看板（大数字指标）+ 近期任务；「重新注册」在顶栏。
- 双端共享同一套 CSS 变量令牌；桌面与窄屏可用（顶栏可换行，宽表可横滑）。
- 行为不回归：离线禁用截图/文件；非 `.txt`/`.gif` 无预览/下载按钮；轮询与 API 不变。

## 2. 非目标（YAGNI）

- 引入 Vite / React / Vue 或其它前端构建链
- Hash / History 路由框架（本期用 JS show/hide）
- 鉴权、主题切换（暗色模式）、国际化多语言框架
- 改后端契约或新增业务 API
- 自动暗色、光晕、呼吸灯、数字滚动计数等装饰动效
- Agent 本机 WebUI 增加文件管理（文件浏览器仍仅在中心）

## 3. 技术路线

**方案：共享设计令牌 + 双端壳层重组（静态 HTML/CSS/JS）**

| 项 | 约定 |
|----|------|
| 交付形态 | 继续 `crates/*/static/` 嵌入静态资源 |
| 样式 | 各自 `style.css`（或等价）；**CSS 变量令牌同名同值** |
| 脚本 | 现有 fetch + 轮询逻辑保留；增加视图切换状态 |
| 字体 | 可选用 CDN 加载 IBM Plex Sans / Condensed；失败时回退系统无衬线。等宽用 `ui-monospace, Consolas, monospace` |
| 同步 | 令牌以本文档为权威；实现时两边复制同一 `:root` 块，不做跨 crate 共享静态管线 |

## 4. 信息架构

### 4.1 调度中心（`:26630`）

```text
┌──────────────────────────────────────────────┐
│ 调度中心          [刷新]    机台 | 作业       │
├──────────────────────────────────────────────┤
│ 「机台」(默认)                                 │
│  Agent 表：状态点、CPU/内存、忙碌              │
│  行操作：截图 | 历史 | 文件                    │
├──────────────────────────────────────────────┤
│ 「作业」                                       │
│  上：模板表单 + 列表                           │
│  下：任务下发 + 列表；行点击展开详情           │
└──────────────────────────────────────────────┘
弹层：截图预览 / 历史列表 / 文件浏览 / 文件预览
```

- 顶栏：**品牌优先**（「调度中心」），分区 Tab「机台 | 作业」。
- 默认视图：机台。切换为 show/hide，无整页导航、本期不做 URL hash。
- 截图、截图历史、文件浏览：保持现有模态交互与中心代理行为，仅换壳层样式。

### 4.2 Agent（`:26631`）

```text
┌──────────────────────────────────────────────┐
│ 产线 Agent                      [重新注册]   │
├──────────────────────────────────────────────┤
│ 状态看板：主机 / IP / CPU / 内存 / 忙碌       │
│ （大数字或简洁指标块，一眼可扫）              │
├──────────────────────────────────────────────┤
│ 近期任务表（只读，沿用现 API）                │
└──────────────────────────────────────────────┘
```

- 首屏一体看板，非仪表盘式多卡片堆砌统计条。
- 指标块允许细边框白底（交互/读数容器）；不做重阴影卡片栈。

## 5. 视觉令牌（产线工控清爽）

用户已确认；背景修订对比后仍锁定原浅灰蓝（选项 C）。

| 令牌 | 值 | 用途 |
|------|-----|------|
| `--bg` | `#e8eef3` | 页面底 |
| `--surface` | `#f4f7fa` | 顶栏、表头浅条 |
| `--panel` | `#ffffff` | 表格、表单、指标块 |
| `--border` | `#c5d0db` | 细边框 |
| `--text` | `#1a2332` | 主文案 |
| `--muted` | `#5a6b7d` | 次要标签 |
| `--accent` | `#0b3d91` | 品牌、主按钮、Tab 选中、链接 |
| `--ok` | `#1f8a4c` | 在线空闲等成功态 |
| `--busy` | `#c47a00` | 执行中 |
| `--err` | `#c0392b` | 离线 / 失败 |
| `--radius` | `4px` | 按钮、Tab、输入 |

其它约定：

- **状态**用色点 + 短文案，不用密集胶囊堆。
- **ID、路径、端口**用等宽字体。
- **圆角**统一 4px；避免大圆角药丸按钮作为默认控件。
- 避免紫渐变、暖奶油+陶土、报纸排版等无关风格漂移。

## 6. 关键组件与交互

| 组件 | 行为 |
|------|------|
| 顶栏 Tab | 「机台 / 作业」切换；选中态填充 `--accent` |
| 机台表 | 状态点颜色随 online/idle/busy/offline；离线行禁用截图/文件 |
| 作业区 | 上模板、下任务；任务行点击在同页展开/聚焦 stdout·stderr（不上独立路由页） |
| 模态 | 截图、历史、文件、预览：遮罩可点关或显式关闭；路径面包屑等宽 |
| 文件行 | 仅 `.txt`/`.gif` 显示预览/下载（行为与现实现一致） |
| 刷新 | 保留手动刷新；后台轮询逻辑不变 |
| Agent 重新注册 | 顶栏主按钮，调用现有注册流程 |

## 7. 动效

克制，建议恰好以下三类：

1. **视图切换**：机台/作业内容区短淡入约 120–180ms。
2. **状态点**：忙闲颜色过渡，无闪烁、无光晕。
3. **模态**：遮罩 + 面板轻微上移淡入；关闭响应快。

禁止：无限循环动画、滚动计数、多层阴影呼吸。

## 8. 静态资源组织（建议）

在不大规模拆框架的前提下，允许按文件拆分以便实现：

```text
crates/scheduler/static/
  index.html
  style.css      # 含共享令牌 :root
  app.js         # 或保留内联，由实现计划决定

crates/agent/static/
  index.html
  style.css      # 同名令牌块
  app.js
```

若实现期选择保留单文件 HTML，须在文档或 PR 说明；令牌值仍须与第 5 节一致。

## 9. 验收清单

- [ ] 调度中心默认「机台」；品牌「调度中心」首屏主导。
- [ ] 「作业」含模板 CRUD 展示与任务下发/列表/详情（与现功能对等）。
- [ ] 截图、历史、文件模态可用且行为不回归。
- [ ] Agent：大数字状态区 + 任务表；重新注册在顶栏。
- [ ] 双端令牌视觉一致；窄屏可操作。
- [ ] 离线禁用与非 txt/gif 无操作按钮仍然成立。
- [ ] 无 API / 调度语义变更。
