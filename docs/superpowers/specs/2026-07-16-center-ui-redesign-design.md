# 调度中心前端改版设计

**日期:** 2026-07-16  
**状态:** 待实现  
**范围:** 调度中心 WebUI 为主；Agent WebUI 仅对齐设计 token（换肤），布局与功能不变

## 背景

当前中心（`:26630`）为顶栏分区「机台 / 作业 / VI」+ 宽表格；Agent（`:26631`）为 VI / 序列工作台。用户希望中心首页改为 **Agent 卡片**，点击进入 **中心内详情**；另设 **已注册功能** 管理页负责列表与分发；中心与 Agent **视觉尽量一致**；Shell「作业」从中心 UI **拿掉**。

## 目标

1. 中心首页以卡片展示每台 Agent；点击进入该 Agent 在中心内的详情页。
2. 新增「已注册功能」页：管理已注册 VI 模板、单目标分发；**不**提供中心侧登记表单。
3. 中心去掉 Shell 作业相关 UI（任务模板、创建任务、任务总表等）。
4. Agent 与中心共用同一套视觉 token；Agent 本轮不改信息架构。
5. 实现方式：单页多视图（hash 路由），继续静态 `index.html` + `app.js` + `style.css`。

## 非目标

- 不新增后端 API（沿用现有 agents / vi-templates / screenshot / files / 按 agent 查任务等）。
- 不上 React/Vite 等新前端栈。
- 不删除或改写调度器 Shell 任务后端（仅中心 UI 不再暴露）。
- Agent 不改页面结构（VI / 序列、注册表单等保持）。
- Agent 详情页不展示「该机已注册功能」列表（统一在「已注册功能」页）。
- 中心不伪造 Agent 本机「运行时间」（中心 API 无该字段；用 `last_seen` 等已有字段）。

## 方案

**采用方案 A：单页多视图（hash）。**

| 路由 | 视图 |
|------|------|
| `#/` 或 `#/machines` | 机台卡片网格 |
| `#/agents/{id}` | Agent 详情 |
| `#/functions` | 已注册功能 |

顶栏：品牌「调度中心」+ 导航 `机台` | `已注册功能` + 刷新。

### 首页 — Agent 卡片

每张卡片展示：

- 电脑名（`name`）
- `IP:端口`
- 在线/离线状态点、是否忙碌
- CPU%、内存%（紧凑指标）

整卡可点 → `#/agents/{id}`。离线卡片视觉降权但仍可进入。空态：「暂无机台」。

### Agent 详情（中心内）

- 「返回机台」+ 电脑名
- **状态概览：** 状态、IP:端口、CPU、内存、忙碌、`last_seen`
- **操作区（保留现能力，改为详情内区块）：** 截图、历史（该 Agent）、文件浏览
- 不包含：已注册功能列表、打开本机 Agent UI 外链（本轮不做）、Shell 作业

### 已注册功能页

- 工具条：按 Agent 筛选、刷新
- **不保留**中心「登记 VI」表单（注册只在 Agent）
- 表格：名称、所属 Agent、VI 路径、来源机、超时/前面板摘要、操作
- 行操作：重命名、分发、删除（与现 API 一致）
- 分发弹层：单选目标 Agent；可选目标路径；警示「分发后源机将不再持有该模板」；成功后刷新列表（transfer 语义不变）

### 从中心 UI 移除

- 顶栏「作业」及全部 Shell 模板/任务表单与列表
- 旧顶栏「VI」大分区（能力由 `#/functions` 承接；中心登记表单删除）

### Agent（`:26631`）本轮

- IA / 功能不变
- `style.css` 对齐中心 CSS 变量与按钮/表格/顶栏基础样式，使两端像同一产品

## 视觉

- 气质：产线控制台 — 冷静、可读、仪器面板感
- 调色：浅冷灰底 + 白面板 + 深蓝强调（避免紫渐变、奶油衬线风、报纸细线风、默认暗色炫光）
- 字体：品牌 condensed 无衬线；正文同家族；数据等宽
- 签名元素：机台卡片网格（状态点 + 紧凑指标）；详情状态条与卡片同构
- 动效：卡片 hover、视图切换短淡入（约 2–3 处），克制

中心与 Agent 共用同名 CSS 变量（颜色、圆角、字族、按钮、表格）。

## 技术约束

- 静态资源仍由 Axum 提供；不改端口约定（中心 26630 / Agent 26631）
- Hash 路由支持浏览器后退
- 刷新：按当前视图重拉对应数据
- 现有模态（截图、文件、历史、分发）迁入新 IA，行为不变

## 成功标准

1. 打开中心首页可见 Agent 卡片；点击进入详情且 URL hash 可分享/可后退。
2. 「已注册功能」可筛选、重命名、单目标分发、删除；无登记表单。
3. 中心任意入口找不到 Shell「作业」UI。
4. Agent 换肤后与中心色板/控件一致，原有 VI / 序列流程可用。
5. `cargo test -p scheduler -p agent` 仍通过（含静态资源相关测试若有）。
